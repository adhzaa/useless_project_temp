### Project Description
This web-based project is a sarcastic review portal designed to simulate user reviews of companies — but with a humorous twist:
No matter what, every review results in a 1-star roast. The intention is to mockingly critique a company with randomly generated roast lines, mimicking exaggerated dissatisfaction in a fun and creative way.

### The Problem (that doesn't exist)
Traditional reviews lack a dramatic visual impact. This webpage fixes that by forcing a real image of the company into the review, so we can judge them with our eyes and our sarcasm.

🎯 Summary:
This project solves the non-existent problem of:

"What if we needed a review system that always assumed the company is terrible, and didn’t let anyone else have an opinion — ever — while showing their logo just to rub it in?"

### The Solution (that nobody asked for)
In a world overflowing with logic, fairness, and multi-user systems, we dared to ask:

“What if someone could roast a company in the most gloriously unproductive way possible… and no one could stop them?”

So we built it.

This project is the ultimate solution to a problem that never existed — a one-user-at-a-time, one-star-only, randomly roasted, image-fueled review system that:

Ignores all actual customer feedback

Rejects usefulness in favor of sarcasm

Assumes the company deserves it — without evidence

Keeps a detailed timestamp, as if anyone will reference it
